# Global Sales & Business Analytics Using SQL Server

## 📌 Overview

A SQL Server project focused on analyzing **sales, customers, products, stores, geography, delivery performance, and financial KPIs** using 50 real-world scenario-based SQL questions.

## 🎯 Objectives

* Analyze sales, revenue, cost, and profit.
* Identify top and high-value customers.
* Analyze product, category, and brand performance.
* Evaluate store and regional performance.
* Analyze delivery efficiency.
* Perform USD and local currency analysis.
* Generate executive-level business KPIs.

## 🗂️ Data Model

**Tables:**

* `Sales` – Fact table
* `Customers`
* `Products`
* `Stores`
* `Exchange Rates`

`Sales` connects to Customers, Products, Stores, and Exchange Rates through keys and date/currency matching.

## 📊 Analysis Areas

* **Sales & Revenue Analysis** – Revenue, AOV, monthly/yearly trends, MoM growth.
* **Customer Analysis** – Top customers, repeat customers, spending, purchasing behavior.
* **Product Analysis** – Best-selling products, brands, categories, profit.
* **Store Analysis** – Store revenue, ranking, size, and performance.
* **Geographic Analysis** – Country, state, and continent performance.
* **Delivery Analysis** – Delivery days and store delivery performance.
* **Financial Analysis** – Revenue, cost, profit, margins, and currency conversion.
* **Demographic Analysis** – Customer age and age-group revenue.
* **Advanced SQL Analysis** – CTEs, subqueries, ranking, window functions, running totals, and `LAG()`.

## 💡 Key KPIs

* Total Revenue (USD)
* Total Cost
* Total Profit
* Profit Percentage
* Total Orders
* Total Customers
* Total Products Sold
* Average Order Value
* Revenue in Local Currency

## 🛠️ Technologies

**SQL Server | T-SQL | Git | GitHub**
